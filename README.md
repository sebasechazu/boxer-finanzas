# Boxer Finanzas 📈

**Boxer Finanzas** es una aplicación creada para ayudar a pequeños negocios, emprendedores y trabajadores independientes a llevar el control de sus cuentas, ventas y deudas de forma simple y ordenada.

### ¿Qué te permite hacer esta aplicación?

- **Registrar ventas y préstamos**: Lleva el registro de los productos que vendes o el dinero que prestas, calculando fácilmente los intereses o recargos.
- **Cobrar en cuotas**: Divide los pagos de tus clientes en cuotas semanales, quincenales o mensuales, según te convenga.
- **Calendario de cobros**: Un tablero principal te muestra de forma visual qué cuotas vencen en los próximos días para que sepas exactamente a quién cobrarle cada día.
- **Seguimiento de clientes**: Consulta en tiempo real la lista de tus clientes y cuánto dinero tiene pendiente de pago cada uno.
- **Catálogo de artículos**: Guarda tus productos con su precio de compra y precio de venta rápida para no tener que recordarlos de memoria.
- **Administrar en equipo**: Invita a tus socios o colaboradores usando su correo electrónico para que puedan ver y gestionar las cuentas del negocio contigo.
